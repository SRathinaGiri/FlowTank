# FlowTank Support

For support, bug reports, and feature requests, use GitHub Issues:

https://github.com/SRathinaGiri/FlowTank/issues

When reporting a problem, include:

- Power BI Desktop or Power BI service version.
- FlowTank visual version.
- A short description of the expected and actual behavior.
- Steps to reproduce the issue.
- A sample PBIX or sanitized data sample when possible.
