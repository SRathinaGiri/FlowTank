# FlowTank Privacy Policy

FlowTank is a Power BI custom visual that renders data already supplied to it by Power BI.

## Data Collection

FlowTank does not collect, store, sell, transmit, or share user data. The visual does not send data to external services and does not make outbound HTTP, HTTPS, WebSocket, `fetch`, or `XMLHttpRequest` calls.

## Data Processing

All calculations and rendering happen locally inside the Power BI visual host. FlowTank uses the report data fields assigned by the report author only to draw the visual during the active Power BI session.

## Local Storage And Cookies

FlowTank does not use browser cookies, local storage, session storage, or other persistent browser storage.
